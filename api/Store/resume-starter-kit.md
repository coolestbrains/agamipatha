# Student resume starter kit

Copy the blocks below into a one-page Word or Google Doc.

## Header

Your name · city · phone · email · LinkedIn or GitHub

## Education

Degree / Class 12 · college or school · year · CGPA or percentage

## Projects (2–3)

Project name — one line on the problem, one line on what you built, one tool list.

## Skills

Languages, tools, and one soft skill you can prove in an interview.

## Cover note (5 lines)

I am a [year] [degree] student looking for a [role] internship. I recently [project or result]. I can start from [date] and work [onsite / remote].
